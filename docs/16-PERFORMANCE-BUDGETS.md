## 7. Measurement & enforcement

- **Benchmarks:** criterion suites in `prism-benches` (scan, arena, layout, ipc) + Playwright-based UI benches (`bench-ui`: scripted interactions measuring frame timings via `requestAnimationFrame` deltas and long-task observer) + `bench-viz` (canvas paint timings via `performance.measure` around paint passes).
- **In-app perf HUD** (`--perf-hud`): overlay showing fps, frame time graph, last IPC latencies, engine queue depth, paint mode (C2D/WebGL) — used by QA and for support conversations; never shipped enabled.
- **CI gates:** `ci-perf.yml` runs all benches on R1/R2 nightly + on release branches; PRs touching `crates/**`, `src/renderer/canvas/**`, or IPC plumbing require a perf-diff comment (bot) and fail on > 10% regression on any hard budget row. Budget table in this doc is mirrored to `perf/budgets.json` (machine-readable, single source for the gate job).
- **Field telemetry (opt-in only):** anonymous p50/p95 of scan duration/files, app cold start, and crash-free rate — aggregate only, no paths ([14 § 4](14-SECURITY-MODEL.md#4-data-handling)); budgets inform but never get secretly widened by field data — widening a budget requires an amendment PR to this file (visible, deliberate).
